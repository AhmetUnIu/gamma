Computer1:

This project is designed to demonstrate Object-Oriented Programming (OOP) concepts in C#.

The code defines a Computer class that stores:

BIOS name, IP address, Operating system (OS)

These fields are accessed using properties, following proper encapsulation principles.


In the Main method:

> Multiple Computer objects are created

> The objects are stored in a List<Computer>

> All computer information is printed to the console



Computer2:

The code defines a Computer class that stores:

BIOS name, IP address, Operating system (OS)

These fields are kept private and accessed through properties, following encapsulation principles.

The class also includes a static counter variable that keeps track of how many Computer objects have been created. Each time a new object is instantiated, the counter is incremented automatically.


In the Main method:

> A number of Computer objects are created

> They are stored in a List<Computer>

> All computer information is printed to the console

> The total number of computers in the network is displayed using the static counter
