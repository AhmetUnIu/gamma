Empv1: 

An Employee class is defined.
The employee’s name, position, salary, and age are stored.
The age is randomly generated between 18 and 77.
An employee object is created in the Main method and printed to the console.


Empv2:

Changes Compared to the Previous Version
Fields (name, position, salary, age) were changed from public to private.
Encapsulation was applied by adding properties (get/set) for each field.
Direct access to class data from outside is prevented.
The code is now more secure and compliant with OOP principles.


Empv3:

Changes Compared to Previous Version
Added a static field counter.
Each time an Employee object is created, counter is incremented by 1.
The total number of employees is printed in Main.
Demonstrates class-level shared data (static usage).
